# Pictogrammes

Le site utilise des **emoji colorés** pour la navigation et les catégories (🏠 Accueil, 🪴 Boutique, 🧺 Sélection, 📞 Contact) et des **illustrations PNG propres à la boutique** (logo, emblème avec carotte, tomate et maison).

Ces illustrations et le logo sont la propriété du site : elles ne sont **pas reproduites** ici. Pour retrouver le style, utiliser des emoji (affichage natif de l'appareil) ou un jeu d'icônes libre aux formes arrondies (par exemple Lucide, voir le design system `poulayo`).
